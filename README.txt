САЙТ «ЦИФРОВАЯ КУЛЬТУРА В ПРОФЕССИОНАЛЬНОЙ ДЕЯТЕЛЬНОСТИ»

Структура проекта:
- index.html — главная страница
- classification.html — классификация инструментов
- documents.html — инструменты для документов и данных
- media.html — графика и мультимедиа
- communication.html — коммуникация и совместная работа
- css/style.css — общие стили
- js/main.js — JavaScript (мобильное меню)
- images/ — локальные иллюстрации SVG

КАК ОТКРЫТЬ В VISUAL STUDIO CODE:
1. Распакуйте ZIP-архив в отдельную папку.
2. Откройте Visual Studio Code.
3. Выберите Файл → Открыть папку и укажите папку «Цифровая_культура_сайт».
4. Откройте index.html.
5. Для просмотра можно нажать правой кнопкой по index.html и выбрать Open with Live Server (если расширение Live Server установлено). Либо просто открыть index.html в браузере.

ВАЖНО:
- Все иллюстрации находятся локально в папке images, поэтому для их отображения интернет не нужен.
- На главной странице замените «Фамилия, имя» на свои данные.
- В проекте использованы авторские векторные иллюстрации SVG, а не фотографии реальных людей.
- Для публикации можно загрузить всю папку проекта в GitHub Pages. Не удаляйте css, js и images: страницы используют эти папки.
